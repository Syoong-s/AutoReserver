# AutoReserve · 现代原生预约客户端

面向体育场馆的现代原生桌面预约客户端。

[English](README.md) | [开发与构建说明](Develop.md)

AutoReserve 结合了高效的原生 GTK 3 桌面交互与自动化的 Playwright 预约工作流。支持单日预约、多场馆/场地优先级备选、按周自动重复模板，以及高精度的开抢抢购模式。

> **重要提示**：AutoReserve 仅自动监测空位并提交订单，**不包含支付功能**。预约成功后，请在官方平台规定的时间内手动完成付款。

---

## 功能介绍

- **原生桌面体验**：采用原生 GTK 3 界面，支持客户端装饰标题栏（CSD）、流畅滚动、键盘导航及全局字号缩放（11–20 px）。
- **多场馆与场地备选**：单个预约目标内可添加多个场馆、项目及具体场地并自定义优先级排序，按优先级命中任意可用项即完成该目标。
- **灵活场地与时段**：支持选择具体场地或“任意可用场地”，支持勾选连续时段合并下单。
- **智能调度与目标复制**：支持一键顺延复制到下一天（`+` 按钮）并保持独立配置，支持灵活的按周重复模板（自定义执行星期、执行时刻及预约天数偏移）。
- **高精度开抢抢购模式**：专为准点放号设计，支持自动化提前预热（默认提前 45 秒）、服务器时钟偏差估算与补偿，并在开抢首秒采用 250ms 高频突发轮询。
- **实时监测与执行记录**：工作台下方常驻展示最近 50 行执行记录与最新空位快照，独立滚动且互不遮挡。
- **清晰状态与原生通知**：左侧栏色条直观展示各目标运行状态（监测中、按周重复、未启动、已完成、需处理）；下单成功后立即弹出原生通知窗口，显示完整订单信息。
- **安全限频与防重保护**：共享全局请求预算与异常指数退避机制。本地持久化事务记录可有效防止程序重启后重复下单。
- **独立目标与历史订单**：保存、开始监测只作用于当前选中目标，其他草稿保留；已下单目标可删除，左栏底部的“历史订单”浮窗可查看和删除本地订单记录。
- **本地私密零云端**：用户认证凭据、会话 Cookie、配置及订单记录完全保存在本地电脑，无任何外部云端上传。

## 快速上手

### 1. 下载与启动

在本仓库的 **Releases** 页面下载对应系统的便携包：

| 系统 | 下载的 Release 包 | 启动方式 |
| --- | --- | --- |
| **Linux x86_64**<br>（Ubuntu 22.04+ / WSLg 图形桌面） | `AutoReserve-xx.xx.xx-linux-x86_64-portable.tar.gz`（或 `.zip`） | 将整个文件夹解压到本地可写路径，双击其中的 **`AutoReserve`**。 |
| **Windows 11 x64** | `AutoReserve-xx.xx.xx-windows-x86_64-portable.zip` | 将整个文件夹解压到 Windows 本地可写磁盘，双击其中的 **`AutoReserve.exe`**；无需安装 Python 或 WSL。（参见 [Windows 说明](docs/WINDOWS.md)）。 |

> **首次启动说明**：请保留启动文件与解压后的其他文件。首次启动时程序会自动在本地文件夹初始化所需的运行组件（如浏览器驱动），需保持网络连接；配置保存在程序文件夹内的 `config/` 中。
>
> *（如需从源码运行、执行测试套件或自行打包，请参阅 [开发与构建说明 (Develop.md)](Develop.md)。）*

### 2. 使用流程

1. **登录认证**：
   点击侧栏 **登录 / 重新登录**，在弹出的浏览器窗口中完成 jAccount 登录。登录完成后返回客户端，点击 **保存登录**。
2. **配置预约目标**：
   点击侧栏 **新建预约目标**，填写目标日期。在下拉框选择场馆、项目、场地及时段后，点击 **加入场馆**。可重复添加多个场馆/场地作为备选，并通过上下箭头调整优先级。
3. **（可选）设置按周重复或抢购模式**：
   - **按周重复**：点击右侧顶部 **设为重复目标** 转换为模板，配置自动执行星期、时刻及往后天数。
   - **抢购模式**：开启右上角 **抢购模式** 滑块，填写完整的开抢日期与时间（精确到秒），并核对预热与突发参数。（参见 [抢购模式说明](docs/RUSH.md)）。
4. **启动监测**：
   在左栏选中目标，点击 **保存目标**，然后点击 **开始监测**。两个按钮只控制选中目标，其他未保存草稿保留；选中重复模板时只调度该模板及其生成的日期目标。保持电脑与网络在线。收到下单成功弹窗后，请及时前往官方平台核对并完成支付。

## 删除目标与历史订单
左栏的 **×** 可以删除已下单目标，立即清理目标草稿、监测进度、旧计划缓存和可归属的执行文件，订单保留在左栏底部的 **历史订单** 浮窗。删除重复模板会一并删除其生成的日期目标；只删除某次日期目标，则跳过该执行日，避免它被再次自动生成。共用登录状态和其他目标不受影响。

相同场馆、场地、日期、时段的新目标若被历史提交记录阻止，提示会注明具体时段、订单及“历史订单”入口。请先核对实际订单，再在浮窗内删除对应的 **本地记录**，即可重新监测；删除本地记录 **不会取消网站订单**。删除一条记录只解除其自身的去重保护，其他订单保留。监测时可查看历史，停止后可删除记录。全局显示与执行偏好仍由设置窗口管理，目标工具栏只作用于当前选择。
